# ApkBolt Privacy Policy

Last Updated: November 2026

ApkBolt is a locally running Windows desktop application. Our principle is absolute: **we do not collect, upload, transmit, or share your personal data.**

---

## 1. What We Do Not Collect

- No account or identity information (ApkBolt has no account system).
- No device identifiers, advertising IDs, or geolocation telemetry.
- Zero analytics, behavioral tracking, or advertising SDKs.
- Zero telemetry sent to remote servers (we maintain no telemetry infrastructure).

---

## 2. Local Machine Data

All data generated by ApkBolt resides strictly on your local PC:

| Location | Description |
|---|---|
| `%APPDATA%\apkbolt\` | System images, installed applications, user data partitions, and snapshots |
| `%USERPROFILE%\ApkBoltShared` | Bi-directional host-guest shared synchronization folder |

---

## 3. Network Communication

- **Updates**: ApkBolt only contacts GitHub Releases when you manually click "Check for Updates" or when first downloading official runtime assets. Requests include only standard HTTP client headers.
- **Android Guest Apps**: Network traffic generated by Android applications running inside ApkBolt is initiated directly by the applications themselves through QEMU user-mode NAT. ApkBolt does not inspect, modify, or log guest network payloads.
